# Personal Portfolio Website

A modern and responsive personal portfolio website created using Google Antigravity for practice and learning purposes.

## About the Project

This project is a personal portfolio website designed with a modern UI/UX approach. It showcases personal information, skills, projects, achievements, and contact details in a clean and interactive layout.

The project was built as a practice project to explore modern frontend development concepts and premium website design styles.

## Features

- Modern responsive design
- Clean and premium UI
- Mobile-friendly layout
- Smooth animations and transitions
- Hero landing section
- About me section
- Skills section
- Projects showcase
- Contact section
- Social media links
- Dark/Light mode UI
- Interactive components

## Technologies Used

- React
- Next.js
- Tailwind CSS
- TypeScript
- Framer Motion
- Google Antigravity

## Project Purpose

This is a practice project created for:
- Learning frontend development
- Exploring modern UI/UX
- Understanding responsive web design
- Practicing component-based architecture
- Building portfolio-style applications
